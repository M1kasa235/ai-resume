## 简历写法

```
AI Job Assistant — 全栈 AI 求职辅助平台

技术栈：FastAPI / LangChain / LangGraph / Chroma / DeepSeek / React

• 构建企业级 RAG 系统：简历 PDF 解析 → 分块 → 向量化 → 混合检索
  （Dense + BM25）→ Reranker 重排，结合 HyDE 和 Multi-Query 优化召回
• 实现 AI 简历优化引擎：简历诊断 → 定向优化（针对 JD）→ 多版本管理，
  基于 LLM 实现项目描述润色、技能补充建议
• 基于 LangGraph 搭建 AI 面试状态机，管理多轮面试的提问→评估→报告全流程
• 实现多工具 AI Agent（网页搜索 + 数据库查询），结合 RAG 提供个性化求职建议
• 引入 RAGAS 评估框架量化检索效果
```

## 风险控制

| 风险 | 概率 | 应对 |
|------|------|------|
| LangGraph 学不会/来不及 | 中 | 退回到方案 B，功能一样 |
| 简历优化来不及 | 低 | 先保证诊断 + 一段优化，版本管理延后 |
| RAG 效果不好 | 中 | Reranker + HyDE 兜底 |
| 时间不够 | 高 | 砍掉：Docker 部署、岗位匹配、面试报告 |
| 部署出问题 | 中 | 本地录屏 demo 也可以 |
